# Raji Farouq Adewunmi

Product design engineer in Lagos, Nigeria. I build for the phone in your
pocket — PWAs and native — and I care about the unsexy parts: tests, bundle
budgets, and not leaking secrets into them.

## Currently shipping

- **[Nearspace](https://github.com/GraphicMiles)** — a location-based creator
  community: geohash-proximity discovery, RTDB presence, cache-first Firestore
  reads, 590+ unit tests and a strict verify pipeline. Production users,
  private codebase; case study on request.
- **[Luna](https://github.com/GraphicMiles/Luna)** — local-first
  AI coding assistant for Android. GGUF models run natively through a
  llama.cpp ↔ JNI ↔ Capacitor bridge with incremental token streaming and a
  checksummed, immutable model catalog. No server required.
- **[Stare](https://github.com/GraphicMiles/stare-ai)** — a real-time staring
  competition in the browser. MediaPipe face-mesh runs as the impartial
  referee. Silly premise, serious CV plumbing.
- **[Photon Lab](https://github.com/GraphicMiles/photon-lab)** — a research
  test bench for screen → camera optical data channels.
- **[Chan](https://github.com/GraphicMiles/chan-watchparty)** — synchronized
  watch-party viewing with its own sync server and a native Android player.
