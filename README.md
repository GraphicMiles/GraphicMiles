# Raji Farouq Adewunmi

Junior full-stack and AI engineer in Ogun, Nigeria. I build web and mobile apps
end to end, from the interface to the backend and the AI features.

Portfolio: **[designedbymiles.vercel.app](https://designedbymiles.vercel.app)**.
Each entry below links to its repository or its live site.

## What I have shipped

- **[Nearspace](https://nearspace.com.ng)** - a location based community for
  creators in Nigeria. Find people working nearby, see who is online, and message
  them one to one or in a group. In production with real users.
- **[Luna](https://github.com/GraphicMiles/forgeai-android)** - a coding assistant
  for Android that runs the model on the phone, so the default path needs no
  server. Heavier models can run hosted.
- **[Legally Unbullied](https://github.com/GraphicMiles/Legallyunbullied)** - a
  Nigerian legal information assistant. It answers from statute and cites the
  provision, or refuses when the sources do not support an answer.
- **[Scout](https://github.com/GraphicMiles/Scout)** - a browser automation
  runtime in Rust, shipped as one small binary with an HTTP API and structured
  extraction.
- **[Mr Nobody](https://github.com/GraphicMiles/Mr-Nobody)** - an Android privacy
  browser with a built in task agent that obeys the same ad and cookie rules you
  set for browsing.
- **[Motionshelf](https://github.com/GraphicMiles/Motionshelf)** - a library of
  copyable UI examples and offline developer tools, with submissions reviewed
  before they are published.
- **[Turf](https://github.com/GraphicMiles/Turf)** - a pay to rank feed where your
  position is the amount you paid, and overtaking a holder costs twice what that
  holder was paid.
- **[Stare](https://github.com/GraphicMiles/stare-ai)** - a staring contest judged
  in the browser by a face mesh. Blink and you lose the round.
- **[Photon Lab](https://github.com/GraphicMiles/photon-lab)** - a test bench for
  sending data from a screen to a phone camera using flashing colour grids.
- **[Middleground](https://github.com/GraphicMiles/Middleground)** and
  **[sweetwater](https://github.com/GraphicMiles/sweetwater)** - first person
  worlds in Three.js. One generates and streams its terrain as you walk, the other
  recreates a town.
- **[Chan](https://github.com/GraphicMiles/chan-watchparty)** - synchronised watch
  parties with chat, screen share and an Android player.
- **ODG Deliveries** and **[ilee](https://designedbymiles.vercel.app/ilee)** - two
  products built for a real operator and used in Lagos: food delivery with one role
  per account, and long term rentals with a staff verification desk. Both
  repositories are private, so ilee links to its portfolio demo instead.
